# 소양강 처녀상 · 손가락 터치형 MR

## 실행 주소
https://imm-content.github.io/soyanggang-cheonyeo-mr/

## 파일 구성
- `index.html`: Three.js 0.165.0 / WebXR 실행 페이지
- `soyanggang-cheonyeo.glb`: 기존 모델 (변경 없음)
- `README.md`: 사용 안내

## 체험 방법
1. WebXR immersive-ar 및 DOM Overlay 지원 Android Chrome에서 HTTPS 주소를 엽니다.
2. 모델 로딩 후 [AR 시작]을 누르고 카메라 권한을 허용합니다.
3. 화면 중앙 십자(+)를 원하는 위치에 맞춥니다.
4. [배치]를 누르면 유효한 카메라 위치 정보가 있는 XR 프레임에서 모델을 배치합니다.
5. 한 손가락으로 회전하고 두 손가락으로 확대·축소합니다.
6. [재배치]를 누르고 새 위치를 조준한 뒤 [배치]를 누릅니다.
7. [AR 종료]로 일반 3D 보기로 돌아갑니다.

## 변경 사항
- Hit Test 및 녹색 원 대기 제거.
- 화면 중앙 십자와 배치/재배치 버튼 추가.
- 카메라 시선 방향 1.8m 지점에 모델 중심을 배치하고 local 기준 공간에 위치 유지.
- 실제 표면의 깊이·높이를 측정하지 않으므로 바닥이나 책상에 정확히 접촉하지 않을 수 있음.
- 카메라 위치 추적 준비 시간은 기기에 따라 다름. 2~3초 이내 시작을 보장하지 않음.
- 기존 GLB 경로와 회전·확대·축소 유지.

## 오류 해결
| 상태 | 확인 방법 |
|---|---|
| AR 시작 불가 | Android Chrome, WebXR 및 DOM Overlay 지원, Google Play AR 서비스 확인 |
| 배치 버튼 비활성 | 카메라 위치 추적 준비 여부 확인, 밝은 곳에서 기기를 천천히 움직이기 |
| 모델이 떠 있거나 바닥에 묻힘 | 실제 표면 인식 대신 고정 거리 배치 방식이므로 조준 위치를 바꾸어 재배치 |
| 변경 전 화면 표시 | 페이지 새로고침 및 GitHub Pages 배포 상태 확인 |

일반 3D 보기에는 카메라 권한이 필요하지 않습니다. 기존 모델 출처 및 라이선스 정보는 그대로 유지하십시오.
