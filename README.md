# 소양강 처녀상 · 손가락 터치형 MR

## 실행 주소
https://imm-content.github.io/soyanggang-cheonyeo-mr/

## 파일 구성
- `index.html`: 실행 페이지 (Three.js 0.165.0, WebXR)
- `soyanggang-cheonyeo.glb`: 기존 3D 모델 (변경하지 않음)
- `README.md`: 실행 및 오류 해결 안내

## 체험 방법
1. WebXR immersive-ar 및 hit-test 지원 Android 스마트폰의 Chrome에서 HTTPS 주소로 접속합니다.
2. 모델이 나타나면 AR 시작을 누르고 카메라 권한을 허용합니다.
3. 밝은 곳에서 책상이나 바닥을 천천히 비춥니다.
4. 녹색 원이 나타나면 화면을 터치하여 동상을 배치합니다.
5. DOM Overlay 지원 환경에서 한 손가락으로 좌우 회전, 두 손가락으로 확대·축소합니다.
6. 재배치 / 초기화 버튼으로 새로운 위치에 배치합니다.

일반 3D 보기에는 카메라 권한이 필요하지 않습니다. 후면 카메라 작동만으로 공간 인식 지원이 보장되지는 않습니다.

## 이번 수정 사항
- 녹색 원 색상·두께·렌더링 우선순위 개선, 컬링 해제
- Hit Test 초기화 실패 및 프레임 오류 발생 시 2초 후 재시도
- 표면 인식 결과 건수와 대기 시간 표시, 15초 이후 안내
- 유효한 pose가 없으면 원을 숨기고 실제 인식 결과가 있을 때만 배치 허용
- AR 종료 이벤트 조기 등록, 이전 세션의 비동기 결과 차단
- 도구 버튼 조작 시 XR 배치 이벤트 차단
- 기존 GLB 경로, 모델 크기, 회전·확대·축소 기능 및 화면 디자인 유지

## 오류 해결
| 상태 | 확인 방법 |
|---|---|
| AR 시작 불가 | Chrome, WebXR 지원 기기, Google Play AR 서비스 확인 |
| 초기화 실패 반복 | 화면에 표시된 오류 이름 확인, AR 종료 후 재시작 |
| 0건 지속 | 조명 개선, 무늬 있는 표면을 여러 각도에서 천천히 비추기 |
| 표면 후보는 있으나 위치 정보 대기 | 기기 추적 상태 확인 |
| 표면 인식 완료인데 원이 안 보임 | 렌더링 및 위치 정보 추가 점검 |

## 검증 범위
원본 HTML 기반 수정 및 JavaScript 문법 검사. 실제 스마트폰에서의 공간 인식 및 배치는 배포 후 확인해야 합니다. 임의의 녹색 원이나 가상 배치 대체 기능은 적용하지 않았습니다.

기존 모델의 출처 및 라이선스 정보가 별도로 관리되고 있다면 그대로 유지하십시오.
